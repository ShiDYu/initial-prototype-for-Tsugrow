# Tsugrow Value Readiness Scan

中小企業経営者が、将来の事業承継に向けた準備状況を約5分・10問で確認するインタビュー用Webプロトタイプです。売却を前提とせず、5領域の自己診断上の準備度、優先確認ポイント3件、最初の90日ロードマップを提示します。

## 起動方法

Node.js 20以上と npm を使用します。

```bash
npm install
npm run dev
```

開発サーバーの案内に表示されるURL（通常は `http://localhost:5173`）をブラウザで開いてください。

## 検証コマンド

```bash
npm test
npm run lint
npm run build
```

静的ホスティングへ配置する成果物は `npm run build` で `dist/` に生成されます。

## 実装範囲

- 匿名の基本情報入力
- 1画面1問の10問ウィザード
- 戻る／次へ／進捗表示とキーボード操作
- `sessionStorage` による同一タブ内の回答復元
- 固定ルールによる総合・5領域の準備度計算
- 優先確認ポイント3件と詳細アコーディオン
- 90日改善ロードマップ
- ブラウザ印刷用レイアウト
- 詳細相談フォームのデモ受付
- レスポンシブ表示と `prefers-reduced-motion` 対応

診断ロジックは [`src/domain/calculateDiagnostic.ts`](src/domain/calculateDiagnostic.ts)、質問・配点・表示文は `src/data/` に分離しています。ルールバージョンは `mvp-1.0` です。

## プロトタイプ上の制約

- 企業価値、株式価値、売却価格、成約確率は算定しません。
- 法務・税務・財務上の正式な判断を行いません。
- バックエンド、ログイン、資料アップロード、決済、AI分析はありません。
- 診断回答はサーバーや外部分析サービスへ送信しません。
- 相談フォームはデモです。入力内容は保存・外部送信されず、送信完了だけを画面上で模擬します。
- 回答は長期保存せず、ブラウザの同一タブ内の `sessionStorage` にだけ一時保存します。
- PDFファイルは生成せず、ブラウザの印刷／PDF保存機能を使用します。

## 暫定ルール

- 同点時の優先順は質問の表示順です。
- 全問が「整理・説明できる」の場合は、影響重みと優先順から重複しない3領域を「維持・確認ポイント」として提示します。
- 優先度ラベルは、質問別リスクスコア0を「維持確認」、6以上を「高」、それ以外を「中」としています。数値自体は画面に表示しません。
- 改善目安は全項目共通で「最初の確認 1〜4週間」です。
